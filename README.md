# BPM Player

Проект-приложение Android, созданный в помощь танцорам. Позволяет управлять локальной базой треков: определить BPM, вручную или при помощи определителя, собрать в плейлист вручную или сгенерировать по заданному диапазону и одному из трёх порядков - случайный, возрастающий или убывающий.

BPM трека виден на всех экранах - чтобы всегда понимать, какая у песни скорость. Редактирование BPM доступно прямо из плеера.

Можно делиться своими аудиотеками: плеер создаёт в папке с музыкой свой служебный файл с информацией о треках, и при повторной загрузке/загрузке на другом устройстве информация подхватится. Также этот файл можно импортировать или экспортировать и передать другому человеку, у которого загружены те же треки.

Проект полностью написан при помощи бесплатной модели OpenCode Big Pickle. Единственное, что написано руками - этот readme.
