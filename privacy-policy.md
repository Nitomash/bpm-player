## 2. Какие данные обрабатывает Приложение
Приложение работает с локальной музыкальной библиотекой, а также может по вашему запросу загружать файлы по публичной ссылке. Приложение обрабатывает следующие данные:

- **Музыкальные папки и файлы, к которым вы предоставили доступ.** Приложение использует выбранные вами папки для чтения аудиофайлов, отображения библиотеки, воспроизведения и работы с плейлистами.
- **Метаданные треков и пользовательские данные внутри Приложения:** названия/пути файлов в рамках выбранных папок, BPM, источник определения BPM, плейлисты, порядок треков и настройки Приложения.
- **Служебные файлы метаданных.** По вашему действию или в рамках синхронизации метаданных Приложение может создавать/обновлять файл `.bpmmeta` в выбранной вами папке с музыкой для хранения информации о треках.
- **Файлы экспорта.** По вашему запросу Приложение может создавать XSPF-плейлисты и копии файлов при экспорте «с файлами» в выбранное вами место.
- **Публичные ссылки на файлы в облачном хранилище.** Если вы используете функцию «Импорт по ссылке», Приложение получает от вас ссылку (в текущей версии поддерживаются публичные ссылки Яндекс.Диска). Ссылка и параметры задачи импорта (имя целевой папки, прогресс, количество файлов) временно хранятся в локальной базе данных Приложения и очищаются после завершения, отмены или ошибки загрузки.
- **Файлы, загруженные по ссылке.** По вашему запросу Приложение считывает структуру папки по ссылке и скачивает поддерживаемые аудиофайлы, XSPF-плейлисты и файлы `.bpmmeta` в выбранную вами папку программы, после чего добавляет их в локальную аудиотеку.

## 3. Разрешения
Приложение может запрашивать следующие разрешения:

- **Доступ к выбранным папкам/документам** (через системный выбор папок Android/SAF) — для чтения аудиофайлов, импорта/экспорта плейлистов, загрузки файлов по ссылке и записи служебных файлов метаданных.
- **Доступ к сети** (`INTERNET`, `ACCESS_NETWORK_STATE`) — для обращения к облачному хранилищу по введённой вами публичной ссылке, проверки доступности сети и скачивания файлов.
- **Уведомления** (`POST_NOTIFICATIONS`, на поддерживаемых версиях Android) — для отображения уведомления управления воспроизведением и хода загрузки по ссылке, если вы предоставите разрешение.
- **Служба воспроизведения в фоновом режиме** (`FOREGROUND_SERVICE`, `FOREGROUND_SERVICE_MEDIA_PLAYBACK`) — для продолжения воспроизведения музыки при работе Приложения в фоне.
- **Фоновая загрузка** (`FOREGROUND_SERVICE_DATA_SYNC`) — для продолжения скачивания файлов по ссылке, когда Приложение работает в фоне. Разрешения `WAKE_LOCK` и `RECEIVE_BOOT_COMPLETED`, добавляемые библиотекой фоновых задач, нужны для завершения начатой загрузки и восстановления заданий после перезагрузки устройства.

Приложение не запрашивает доступ к контактам, геолокации, камере, микрофону, SMS, журналу вызовов или списку установленных приложений.

## 4. Хранение данных
Данные библиотеки, BPM, плейлисты и настройки хранятся локально на вашем устройстве. Служебные файлы `.bpmmeta` и экспортированные файлы сохраняются в местах, выбранных вами. Файлы, скачанные по ссылке, сохраняются в выбранной вами папке программы; сама ссылка хранится в локальной базе данных только до завершения загрузки.

В зависимости от настроек системы Android резервное копирование устройства может включать данные Приложения. Управлять резервным копированием можно в настройках Android/аккаунта Google.

## 5. Передача данных третьим лицам
Приложение не продаёт ваши персональные данные и не передаёт их третьим лицам для их собственных целей — аналитики, рекламы или профилирования.

Приложение не передаёт вашу музыкальную библиотеку, плейлисты, BPM или содержимое аудиофайлов разработчику или третьим лицам через собственные серверы, так как не использует серверную часть и не содержит аналитики/рекламных SDK для сбора таких данных.

Единственный случай обращения в сеть — импорт по ссылке. По вашему явному действию Приложение обращается напрямую к облачному хранилищу, на которое указывает введённая вами ссылка (в текущей версии — Яндекс.Диск, API `cloud-api.yandex.net`), чтобы получить структуру папки и адреса для скачивания файлов. Этому хранилищу передаётся только сама публичная ссылка (публичный ключ) и стандартные запросы на чтение запрошенных вами файлов. Локальная библиотека, плейлисты, BPM, метаданные и содержимое уже имеющихся на устройстве аудиофайлов при этом не отправляются. Файлы скачиваются напрямую с серверов хранилища в выбранную вами папку на устройстве, без участия серверов разработчика.

Данные могут покидать Приложение только по вашему явному действию, например при экспорте плейлиста, экспорте с файлами, сохранении `.bpmmeta` в выбранную папку, импорте по ссылке (запрос к указанному вами хранилищу и загрузка файлов) или при использовании системных функций Android (резервное копирование, передача файла через другое приложение).

## 6. Сторонние библиотеки
Приложение использует сторонние библиотеки для своей работы, включая библиотеки воспроизведения, определения BPM, сетевого взаимодействия и фоновых задач. Эти библиотеки используются в рамках функций Приложения. ## 9. Удаление данных
Вы можете удалить данные Приложения следующими способами:

- удалить папки, треки, плейлисты или служебные файлы `.bpmmeta` через Приложение/файловый менеджер, если применимо;
- удалить загруженные по ссылке файлы вместе с папкой программы через Приложение или файловый менеджер;
- очистить данные Приложения в настройках Android (это также удалит сохранённую ссылку и информацию о задаче импорта);
- удалить Приложение с устройства.
