# Политика конфиденциальности приложения «BPM Player»

Дата вступления в силу: 14.11.2026  
Последнее обновление: 14.11.2026

## 1. Общие сведения
Настоящая Политика конфиденциальности описывает, как приложение «BPM Player» (далее — «Приложение») обрабатывает информацию при использовании на устройствах Android.

## 2. Какие данные обрабатывает Приложение
Приложение предназначено для работы с локальной музыкальной библиотекой и обрабатывает следующие данные на вашем устройстве:

- **Музыкальные папки и файлы, к которым вы предоставили доступ.** Приложение использует выбранные вами папки для чтения аудиофайлов, отображения библиотеки, воспроизведения и работы с плейлистами.
- **Метаданные треков и пользовательские данные внутри Приложения:** названия/пути файлов в рамках выбранных папок, BPM, источник определения BPM, плейлисты, порядок треков и настройки Приложения.
- **Служебные файлы метаданных.** По вашему действию или в рамках синхронизации метаданных Приложение может создавать/обновлять файл `.bpmmeta` в выбранной вами папке с музыкой для хранения информации о треках.
- **Файлы экспорта.** По вашему запросу Приложение может создавать XSPF-плейлисты и копии файлов при экспорте «с файлами» в выбранное вами место.

## 3. Разрешения
Приложение может запрашивать следующие разрешения:

- **Доступ к выбранным папкам/документам** (через системный выбор папок Android/SAF) — для чтения аудиофайлов, импорта/экспорта плейлистов и записи служебных файлов метаданных.
- **Уведомления** (`POST_NOTIFICATIONS`, на поддерживаемых версиях Android) — для отображения уведомления управления воспроизведением, если вы предоставите разрешение.
- **Служба воспроизведения в фоновом режиме** (`FOREGROUND_SERVICE`, `FOREGROUND_SERVICE_MEDIA_PLAYBACK`) — для продолжения воспроизведения музыки при работе Приложения в фоне.

Приложение не запрашивает доступ к контактам, геолокации, камере, микрофону, SMS, журналу вызовов или списку установленных приложений.

## 4. Хранение данных
Данные библиотеки, BPM, плейлисты и настройки хранятся локально на вашем устройстве. Служебные файлы `.bpmmeta` и экспортированные файлы сохраняются в местах, выбранных вами.

В зависимости от настроек системы Android резервное копирование устройства может включать данные Приложения. Управлять резервным копированием можно в настройках Android/аккаунта Google.

## 5. Передача данных третьим лицам
Приложение не продаёт ваши персональные данные.

Приложение не передаёт вашу музыкальную библиотеку, плейлисты, BPM или содержимое аудиофайлов разработчику или третьим лицам через собственные серверы, так как не использует серверную часть и не содержит аналитики/рекламных SDK для сбора таких данных.

Данные могут покидать Приложение только по вашему явному действию, например при экспорте плейлиста, экспорте с файлами, сохранении `.bpmmeta` в выбранную папку или при использовании системных функций Android (резервное копирование, передача файла через другое приложение).

## 6. Сторонние библиотеки
Приложение использует сторонние библиотеки для своей работы, включая библиотеки воспроизведения и определения BPM. Эти библиотеки используются локально в рамках функций Приложения. Актуальную информацию о компонентах и лицензиях можно найти в исходном коде: https://github.com/Nitomash/bpm-player (файлы `LICENSE` и `THIRD_PARTY_NOTICES.md`).

## 7. Дети
Приложение не предназначено специально для детей и не осуществляет knowingly сбор персональных данных детей. Если вы считаете, что ребёнок предоставил персональные данные, свяжитесь с разработчиком по указанному email.

## 8. Безопасность
Мы принимаем разумные меры для обработки данных в пределах возможностей Приложения. Однако ни один способ хранения или передачи данных не может быть гарантированно безопасным.

## 9. Удаление данных
Вы можете удалить данные Приложения следующими способами:

- удалить папки, треки, плейлисты или служебные файлы `.bpmmeta` через Приложение/файловый менеджер, если применимо;
- очистить данные Приложения в настройках Android;
- удалить Приложение с устройства.

## 10. Изменения политики
Мы можем обновлять эту Политику конфиденциальности. Актуальная версия будет опубликована по тому же URL с указанием даты обновления.
